# TapGloss 设计

## 产品目标与范围

TapGloss 是用于普通网页阅读的浏览器扩展，将查询、理解、采集和 Anki 制卡连接为一个连续动作。正常查询流程不包含“加入 Anki”步骤。

- 支持桌面 Chrome / Chromium 和 Firefox。
- 默认在所有允许扩展注入的普通网页工作，不要求逐站启用。
- 面向通用语言与阅读内容，学习材料使用目标语言，界面语言独立。
- 产品界面包括小型查询弹窗、记录管理页、独立词表页和精简设置页。记录、词表、设置共用顶部导航。
- Anki 负责复习与调度；TapGloss 负责阅读辅助、材料保存及导出。

不实现移动端、Safari、独立阅读器、PDF 引擎、OCR、字幕平台、内置复习系统、学习统计面板、AI 聊天、云账号服务或插件系统。

领域术语见 [CONTEXT.md](../CONTEXT.md)。

## 阅读交互与状态

外观提供自动、浅色和深色。自动模式下查询弹窗跟随阅读区域的配色，记录页跟随系统，Anki 卡片跟随 Anki 夜间模式。

查询手势支持直接点击和修饰键加点击两种配置。查询弹窗打开时，点击另一个可查询词直接切换内容，点击空白关闭。词语保留在原有句子排版中，通过轻微底色或下划线提示状态，不渲染成带边框的按钮串。

| 状态               | 页面行为                                                   |
| ------------------ | ---------------------------------------------------------- |
| 尚未处理、需要关注 | 轻微标记，可查询                                           |
| 学习中             | 使用可区分的轻微标记，可查询                               |
| 认识               | 恢复普通正文，普通点击不触发查询，仍可选中后通过快捷键查询 |

- 没有导入词表时，默认将尚未认识的词作为可关注对象。
- 首次查询进入学习中；认识由用户明确标记。
- 查询不覆盖用户明确标记的认识状态。
- 标记认识只改变阅读提醒，不删除来源、生成材料或 Anki 笔记。
- 状态在已确认属于同一表达的词形间共享。以后确认的新词形沿用表达状态，不猜测所有未见词形。
- 页面标记依据本地词汇数据，不为整页分词、高亮或逐句判义调用 LLM。
- 用户可配置忽略语言列表，默认为空；列表中的语言不高亮、不响应普通点击或修饰键点击，主动选中后按 Alt + Q 仍可查询。该列表独立于认识状态、词表及历史记录。
- 语言预判使用浏览器本地 TinyLD light，覆盖 24 种语言。按所在句子识别并缓存，综合文本结果、页面语言标记及所选词的文字体系，避免把中文句子内的英文词一起排除。低置信或含糊结果不强行排除；生成内容的语言仍由 LLM 判断。
- 保存或移除忽略语言后，已打开页面刷新本地标记，无需重新载入网页。
- 不高亮的表达仍可查询，熟悉的表达可能具有陌生义项。

## 查询与生成

查询流程：

1. 本地定位所选表达，提取原句、句内选中位置与来源信息。
2. 立即持久化采集记录并显示原文弹窗。
3. 向 LLM 发送所选表达、整句及句内位置，不发送整页。
4. 校验结构化输出，保存完整生成批次，关联学习条目。
5. 弹窗显示结果，学习材料自动导出到 Anki。

同一句出现多个相同字符串时，通过位置区分被选中的那一次。LLM 可以根据上下文识别完整短语，识别结果必须能映射回原文位置。

模型输出包含语言、识别后的目标表达及其原句位置、规范词形、上下文义项、三条中短例句及各自的目标位置，并可包含简短的目标语言释义。语言由 LLM 判断，不要求用户设置默认学习语言。

例句围绕同一表达的同一义项，使用常用词和简单结构，避免引入多个额外难点。原文与生成例句在视觉和数据上分开，原文不被模型输出替换。

结构校验与位置校验不能保证语义正确，记录页提供内容纠正入口。数据库身份和 Anki 笔记身份由应用管理，不由模型生成或改写。

查询弹窗的头部展示目标表达与短释义，中间显示原文及紧凑的三条编号例句，底栏集中放置保存状态、认识/学习中操作和记录入口。正文过长时中间区域滚动，头尾操作区域保持可见。弹窗不进行挖空测验，不默认输出长篇语法解释或翻译成界面语言，不堆放管理工具栏。

LLM 使用可配置端点、模型和凭据的 OpenAI 兼容 API，支持本机与局域网端点，不依赖特定供应商。界面采用中性黑白灰配色。设置页宽屏采用两条独立纵向排列的列，窄屏折为单列；展开提示词不改变另一列的卡片间距。记录与设置页共用顶部导航区和当前页操作区，记录大小切换和保存分别位于当前页操作区。保存按钮固定文案“保存”，提交时边缘显示加载动画，成功后绿色背景白色文字；编辑后恢复默认，不显示额外的成功横幅。所有下拉共用相同外观及点击、键盘交互，模型额外允许手动输入。帮助说明收在各卡片右上角的问号中，支持悬停、键盘访问与点击固定，提示中的链接可直接点击。AI 连接与查询手势分别配置。输入只修改草稿，切换记录/设置页保留草稿；关闭页面时提示未保存修改。保存只持久化配置，不触发模型发现、连接测试或失败任务重试。点击“获取模型”才发送发现请求，列表返回不自动更换已选模型。连接测试由用户主动触发，退出设置时取消未完成的测试和发现请求。模型下拉展示完整列表，不按当前选中值过滤；连接测试不保存学习记录或创建笔记。生成提示词可编辑并恢复默认，仅影响之后的查询，输出仍须通过结构与位置校验。

## 数据关系与重复查询

本地保存材料的用途是驱动阅读状态、复用查询结果、积累语境，以及可靠地导出到 Anki。

- **采集记录**保存用户实际看到的原文、选中位置、页面来源及必要语言信息。身份来自稳定来源事实，不使用生成释义、生成词元、时间戳或 Anki ID 作为身份依据。
- **学习条目**按同一语言、同一表达的同一义项组织，可关联多条采集记录。
- **生成批次**整体保存。重新生成时保留批次边界，不静默拼接不同批次的句子。

| 情况                                   | 行为                                                         |
| -------------------------------------- | ------------------------------------------------------------ |
| 原句原位置重复查询，包括刷新后再次查询 | 复用已有记录与结果，不重复生成或制卡                         |
| 同一表达出现在新上下文                 | 保存新的来源，判断当前义项                                   |
| 新上下文属于已有义项                   | 关联已有学习条目，追加原文来源，不增加正面例句或重复创建笔记 |
| 新上下文属于不同义项                   | 创建独立学习条目和对应笔记                                   |
| 普通时态、单复数等变化，义项相同       | 可归入同一条目，保留实际遇到的词形                           |
| 不同近义词或独立短语                   | 分别组织，不因含义接近而合并                                 |

学习条目使用持久身份。LLM 的规范词形和义项判断用于建立关联，不能把生成释义文本直接当作身份。

## Anki 卡片与导出

通过 AnkiConnect 连接本地 Anki，使用专用 Cloze 笔记类型。设置页提供只读连接测试，核验接口版本和读取权限，不创建或修改卡片。一份学习条目对应一份受管理笔记，默认生成一张卡片。

正面包含三条中短例句，各句的目标表达使用相同的 `c1` 编号。复习目标是根据语境回忆目标表达，三句共同完成一次复习判断，不要求键入精确匹配答案。

背面揭晓三条例句中的答案，仅追加可选的目标语言短释义与默认折叠的原文来源，不重复显示三条例句或大标题。新遇到的同义语境追加到背面来源材料中，正面不随查询次数无限增长。既有笔记原地更新以保留复习历史；模板样式升级只替换未经用户修改的默认样式。

弹窗与卡片消费同一份已保存生成材料，不为 Anki 单独调用模型。

- 内容就绪后自动导出，不要求额外点击加入按钮。
- Anki 不可用时保留本地材料和待处理任务，不阻塞阅读。网络、限流与临时服务错误采用退避重试，单个任务最多自动尝试五次；鉴权、参数、结构校验、归属或人工修改冲突直接暂停，用户可明确重试。错误分类使用类型与状态码，不匹配提示文字。
- 请求结果不确定时，先按稳定身份核实是否已执行，再决定重试，避免盲目创建重复笔记。
- 内容更新修改原有关联笔记，不通过删除重建更新内容，保留复习历史。
- 检测到 Anki 中的学习内容被人工修改时，不自动覆盖。
- 不识别、导入、匹配或接管其他来源的已有笔记，不提供字段映射和重复候选管理。
- 每台设备可导出本机创建的材料；仅从 TapGloss 同步收到的条目不自动创建另一份 Anki 笔记，由 Anki 自身负责笔记同步。
- 完全离线的多台设备独立创建同一学习内容而产生重复笔记时，不静默删除已有笔记及复习历史。

## 记录管理与删除

记录页提供全库搜索、查看来源与生成材料、纠正内容、调整阅读状态及处理失败任务的能力，不包含统计图表。以十万条学习记录作为性能参考规模。

- 每页最多读取与渲染 100 条摘要，翻页不累积 DOM。默认按创建时间倒序；搜索对词条、释义和全部保留来源建立分词索引，支持词语前缀匹配。
- 标准布局展示当前页例句，紧凑布局只显示按内容宽度排列的词条与轻量状态，不常驻认识、编辑和删除图标。
- 点击词条打开单个居中浮窗，详情按需读取，不改变列表位置。认识、编辑、删除与失败重试集中在浮窗；同一时间只有一个详情。来源按每组 20 条读取。
- UI 首次读取当前页，之后接收成功写入后的变更通知。没有数据变化时不周期读取；隐藏页面断开订阅，恢复时核对变更版本。查询弹窗只刷新当前记录，不拉取整个词汇库。
- 网页只处理可见及邻近正文块，词汇状态按页面需要的词形批量查询。DOM 变化只使相关文本块失效；认识状态修改会通知已打开的页面。

- 删除一条来源仅移除该来源，不等于删除整个学习条目或 Anki 笔记。
- 删除整个学习条目时显示确认，清楚说明删除范围。
- 确认中提供默认不勾选的“同时删除 Anki 笔记”选项。
- 不勾选时保留 Anki 笔记；勾选时只允许删除该条目关联且能验证为 TapGloss 创建的笔记。
- 不按目标词文字或整个牌组执行联动删除，不修改或删除其他已有笔记。
- 删除操作保留必要的同步删除标记，旧设备恢复连接不能自动复活已删除内容。

## 词表与提醒基线

词表使用独立页面，导入、预览、启用、停用与移除均在该页面完成，不放进设置页或记录列表。顶部当前页操作区提供导入入口，页面主体展示已导入词表及其启用状态。设置页不重复提供词表管理操作。

支持用户导入词频表、考试词表及个人排除表，不内置或维护权威词汇数据集。导入支持 TXT 与简单 CSV/TSV，导入前展示预览。

输入使用 UTF-8，每份最多 10 MB、十万个词语。按词语列读取简单词频表，对大小写与 Unicode 规范形式归一化并去重。默认用途为“忽略表内词”，另可选择“只提醒表内词”；多份后者取并集，再排除忽略表中的词。用户明确标记的认识/学习中状态优先。词表只改变提醒与普通点击入口，主动选中后的 Alt + Q 查询始终可用。

词表元信息与不可变内容分开同步，词语匹配索引在本地重建。只收到元信息而尚未收到内容时，不启用不完整的提醒基线；管理页仅读取名称、数量与启用状态，不加载全部词语。启停与移除会通知已打开的阅读页面。

导入基线、个人词汇状态和查询历史独立保存：

- 基线用于减少或筛选提醒，不代表实际掌握程度。
- 个人明确标记的认识/学习中状态优先于基线。
- 被基线排除的表达不自动标记为认识。
- 停用或替换词表不删除个人状态和采集记录。
- 导入词表参与数据同步，其他设备不需要重复导入。

## 本地持久化与同步

LLM、Anki 和远程存储是独立能力。LLM 不可用时保留来源并可重试生成；Anki 不可用时等待导出；远程存储不可用时继续使用本地数据。关闭弹窗或页面不丢失已持久化的工作。任务队列有待执行项才安排下一次唤醒，队列为空时不保留周期闹钟；只读 UI 不唤醒任务。显式重试不覆盖正在执行的任务。扩展只在首次安装时自动打开设置，普通更新不打开管理页。

支持 S3 兼容存储和 WebDAV，共用应用层合并逻辑。一个工作区同时配置一个远程后端，不进行多云镜像。凭据仅本地保存，不纳入普通用户数据同步。首版不要求客户端内容加密。

同步默认关闭。启用后每五分钟执行一次，也提供立即同步；保存配置只安排后续同步，不立即联网。连接测试仅读取远程目录，失败不写入远程数据。临时连接错误退避至最长一小时；权限与格式错误暂停自动同步，修改连接配置或主动同步可继续。后台重启保留已有调度与暂停状态。

共享数据不包含本机 Anki 绑定、任务、凭据或界面设置。业务修改与待同步字段变化原子保存，远程合并不重新产生本地修改事件。固定 64 个分片限制单次加载范围；每台设备分别写自己的分片快照，按远程版本标识下载发生变化的文件。只上传存在本地修改或尚未确认上传成功的分片，接收其他设备的修改不反复转发；无变化时仅读取远程目录。单分片限定 32 MiB，不支持的版本或不合法内容不应用。

删除以可累积的标记参与合并。显式恢复只确认本机已见过的删除；并发而未被确认的删除继续生效。生成批次整体保存，普通字段与词汇状态使用 Yjs 的确定性合并，已见词形累积保留。设备墙上时钟不参与跨设备冲突判定。本地删除观察时间仅用于阻止先前启动的生成任务恢复刚被删除的条目。

同步接收后更新记录索引，并仅为持有本机 Anki 绑定的条目安排导出。可选 Anki 删除仍需在当前设备核验笔记身份，不作为共享任务传播。首次迁移保留原有笔记绑定和任务身份。

Yjs 限定在存储与同步边界内：

- 普通字段的并发修改使用原生确定性合并，无需用户处理冲突，不设置“学习中优先”等额外策略。
- 不用设备墙上时钟作为唯一冲突解决依据。
- 独立来源和完整生成批次分别保存，避免覆盖整个条目时丢失其他设备的独立新增内容。
- 通过更新和快照实现离线副本收敛；S3/WebDAV 负责传输，不负责业务冲突判定。
- 删除标记和生命周期规则保证旧数据不意外复活。
- Anki 创建、更新与可选删除使用身份核验及可恢复任务保证副作用安全，不把 CRDT 合并当作外部操作的幂等保证。

不引入协作服务器、在线状态、共享光标、y-websocket 或 y-webrtc。

## 技术与模块边界

界面语言支持自动、中文和英文。自动跟随浏览器语言，非中文使用英文；偏好只保存在本机。翻译限定为界面文案与受控错误信息，原文、用户命名和模型生成材料不参与翻译。

使用单一扩展项目：TypeScript 严格模式、WXT、Preact、Tailwind CSS v4；页面注入 UI 使用 Shadow DOM 隔离样式。IndexedDB 与 Dexie 负责本地持久化、索引及任务；Yjs 负责共享数据合并；Zod 校验外部输入；Vitest 和 fast-check 用于行为及合并性质验证。

| 模块           | 职责                                                       |
| -------------- | ---------------------------------------------------------- |
| `entrypoints/` | WXT 页面、后台和设置入口，装配配置及依赖                   |
| `src/page/`    | 页面文本、选区、上下文捕获和高亮                           |
| `src/domain/`  | 普通类型表示的采集记录、学习条目、生成批次、词汇状态与操作 |
| `src/storage/` | 本地持久化、查询索引和可恢复任务                           |
| `src/explain/` | 模型请求与结构化结果校验                                   |
| `src/anki/`    | AnkiConnect、笔记构建、导出及操作恢复                      |
| `src/sync/`    | Yjs 边界、共同同步算法、S3/WebDAV 传输                     |
| `src/ui/`      | 查询弹窗、记录页与设置组件                                 |

领域函数显式接收配置和依赖，不隐藏读取全局配置。页面、UI、模型及 Anki 模块不直接操作 Yjs 类型。S3/WebDAV 使用成熟的浏览器兼容库，不自行实现签名或协议。
